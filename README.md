## О проекте

Репозиторий содержит 8 практических работ по операционным системам. Все задания выполняются в Ubuntu WSL2 по варианту A методических указаний.

## Практические работы

| № | Тема | Содержание |
|---|---|---|
| [PR1](pr01/README.md) | Установка Linux и работа с терминалом | базовые команды, информация о системе, права доступа |
| [PR2](pr02/README.md) | Bash и системные вызовы | подсчёт ошибок в 50 журналах, `strace` для `ls` и `cat` |
| [PR3](pr03/README.md) | Процессы в Linux | `ps` и `/proc`, `fork()` и `wait()`, зомби-процесс |
| [PR4](pr04/README.md) | Многопоточность | гонка данных, потоки в `/proc`, многопоточная загрузка файлов |
| [PR5](pr05/README.md) | Алгоритмы планирования CPU | симулятор FCFS, SJF, Round Robin, диаграммы Ганта |
| [PR6](pr06/README.md) | Синхронизация потоков | `Lock`, переводы между счетами, производитель–потребитель |
| [PR7](pr07/README.md) | Межпроцессное взаимодействие | pipe, FIFO, разделяемая память, сигналы |
| [PR8](pr08/README.md) | Взаимоблокировки | граф ожидания, обедающие философы, алгоритм банкира |

## Запуск

Откройте нужную папку `pr01`–`pr08` и следуйте инструкциям в её `README.md`.
В PR3 и PR5–PR8 есть скрипт `run_all.sh`, который запускает все программы работы
и сохраняет их вывод в файлы результатов (`results_*.txt`, в PR5 — `results.txt` и `test_results.txt`):

```bash
cd pr08
bash run_all.sh
```

Для выполнения Linux-команд требуется Ubuntu или WSL2.
