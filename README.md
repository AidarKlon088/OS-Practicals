# Практические работы по операционным системам

**Выполнил:** Айдар Нурбекович  
**Учебное заведение:** Salymbekov University  
**Дисциплина:** Операционные системы

## О проекте

Репозиторий содержит 8 практических работ по операционным системам. Все задания выполняются в Ubuntu WSL2 по варианту A методических указаний.

## Практические работы

| № | Тема |
|---|---|
| PR1 | Установка Linux и работа с терминалом |
| PR2 | Bash и системные вызовы |
| PR3 | Процессы в Linux |
| PR4 | Многопоточность |
| PR5 | Алгоритмы планирования CPU |
| PR6 | Синхронизация потоков |
| PR7 | Межпроцессное взаимодействие |
| PR8 | Взаимоблокировки |

## Технологии

- Ubuntu WSL2
- Bash
- Python
- Git и GitHub
- GCC
- VS Code

## Запуск

Откройте нужную папку `pr01`–`pr08` и следуйте инструкциям в её `README.md`.

Для выполнения Linux-команд требуется Ubuntu или WSL2.

## Результат

Каждая практическая содержит исходный код, команды запуска, результаты выполнения и объяснение изученных механизмов операционной системы.
