### Права доступа

Команда `ls -la` показала:

```text
-rwxrwxrwx 1 user user 62 Oct 27 21:49 about.txt
```

Объяснение:

- `-` — обычный файл.
- `rwxrwxrwx` — чтение, запись и выполнение для всех категорий пользователей.
- `1` — количество жёстких ссылок.
- `user` — владелец файла.
- `user` — группа файла.
- `62` — размер в байтах.
- `Oct 27 21:49` — время изменения.
- `about.txt` — название файла.

Права `777` отображаются из-за особенностей доступа WSL к файловой системе Windows.
