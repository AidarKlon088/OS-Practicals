### Права доступа

Команда `ls -la` показала:

```text
-rwxrwxrwx 1 user user 62 Oct 27 21:49 about.txt
```

Объяснение:

- `-` — обычный файл.
- `rwxrwxrwx` — чтение, запись и выполнение для всех категорий пользователей.
- `1` — количество жёстких ссылок.
- `user` — владелец файла.
- `user` — группа файла.
- `62` — размер в байтах.
- `Oct 27 21:49` — время изменения.
- `about.txt` — название файла.

Права `777` отображаются из-за особенностей доступа WSL к файловой системе Windows.

## Ответы на контрольные вопросы

> Вопросы методички недоступны; ниже — ответы на типовые вопросы по теме.

1. **Что такое WSL2 и чем он отличается от виртуальной машины?** Windows Subsystem
   for Linux 2 запускает настоящее ядро Linux в лёгкой виртуальной машине Hyper-V,
   встроенной в Windows. В отличие от обычной ВМ, она стартует за секунды, сама
   выделяет память по мере необходимости и даёт доступ к дискам Windows через `/mnt/c`.
2. **Что показывают `whoami`, `pwd` и `uname -a`?** `whoami` — имя текущего пользователя;
   `pwd` — абсолютный путь текущего каталога; `uname -a` — имя ядра, имя хоста,
   версию и сборку ядра, архитектуру (`x86_64`).
3. **Чем ядро отличается от дистрибутива?** Ядро (`6.18.33.2-microsoft-standard-WSL2`)
   управляет процессами, памятью и устройствами. Дистрибутив (Ubuntu 26.04.1 LTS) —
   это ядро плюс системные утилиты, менеджер пакетов и программы. Версию дистрибутива
   показывает `lsb_release -a`, версию ядра — `uname -r`.
4. **Чем `>` отличается от `>>`?** `>` перенаправляет вывод в файл, перезаписывая его
   (создаёт, если файла нет); `>>` дописывает в конец файла. Поэтому первая строка
   `about.txt` записана через `>`, а вторая — через `>>`.
5. **Зачем `mkdir -p`?** Создаёт все недостающие каталоги пути и не выдаёт ошибку,
   если каталог уже существует.
6. **Как читать права `rwxr-xr--`?** Первый символ — тип (`-` файл, `d` каталог,
   `l` ссылка), затем три тройки: владелец, группа, остальные; `r` — чтение,
   `w` — запись, `x` — выполнение (для каталога — вход в него). В числовой записи
   `r=4, w=2, x=1`, поэтому `rwxr-xr--` = `754`.
7. **Почему у `about.txt` права `777`?** Файл лежит на диске Windows (`/mnt/c`), где нет
   прав Linux. WSL по умолчанию показывает для таких файлов `rwxrwxrwx`, а `chmod` на
   них не действует без опции монтирования `metadata`. В домашнем каталоге Linux
   (`~`) новый файл получил бы обычные права `644` (`rw-r--r--`).
8. **Чем абсолютный путь отличается от относительного?** Абсолютный начинается с `/`
   (от корня: `/mnt/c/Users/user/Desktop/OS-Practicals`), относительный отсчитывается
   от текущего каталога (`pr01/about.txt`, `../pr02`).
